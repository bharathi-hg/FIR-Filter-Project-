FIR Filters Project using Python

This project implements a Finite Impulse Response (FIR) filter using Python.
An FIR filter is a digital signal processing (DSP) system that processes an input signal using a set of predefined filter coefficients. The filter produces an output signal by calculating the weighted sum of the current and previous input samples.
Python is used to generate the input signal, design and apply the FIR filter, visualize the input and filtered signals, and analyze the filter response.

🎯 Objectives

Understand the fundamentals of FIR filters.
Implement an FIR filter using Python.
Generate and process digital signals.
Apply filter coefficients to an input signal.
Compare the original and filtered signals.
Visualize the filtering process using graphs.
Analyze the frequency response of the FIR filter.
